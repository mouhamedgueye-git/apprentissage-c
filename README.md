# Apprentissage du langage C

Bienvenue dans mon dépôt consacré à mon apprentissage du langage C.

L'objectif de ce dépôt est de pratiquer la programmation en C, de consolider mes bases et de développer progressivement des projets, des plus simples aux plus complexes.

## 🎯 Objectifs

- Comprendre les bases de la programmation en C.
- Apprendre à utiliser les variables, les types de données et les opérateurs.
- Maîtriser les conditions et les boucles.
- Apprendre à utiliser les fonctions.
- Comprendre la gestion des entrées et sorties.
- Améliorer progressivement la structure et la qualité de mon code.
- Développer des projets pratiques pour mettre en application mes connaissances.

## 📂 Projets

### 1. Calculatrice en C
Un programme qui me permet de pratiquer les opérations arithmétiques et les bases de la programmation.

### 2. Carte d'identité en C
Un programme permettant d'afficher des informations sous la forme d'une carte d'identité. Ce projet me permet de pratiquer l'affichage et la manipulation des données.

### 3. Projets à venir
D'autres projets seront ajoutés au fur et à mesure de mon apprentissage.

Chaque projet disposera de son propre dossier et d'un README présentant son objectif, son fonctionnement et les notions de C utilisées.

## 🛠️ Outils utilisés

- **Langage :** C
- **Éditeur :** Visual Studio Code
- **Compilateur :** GCC
- **Gestion de versions :** Git et GitHub

## 💻 Compiler et exécuter un programme

Avec GCC, il est possible de compiler un fichier C à l'aide de la commande suivante :

```bash
gcc programme.c -o programme
```

Sous Windows, pour exécuter le programme compilé :

```powershell
.\programme.exe
```
